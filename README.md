# Graspy

Пет-проект для учёта личных финансов: транзакции по вложенным категориям, отчёты за произвольный период, финансовые цели и рекомендации по тратам. Плюс совместные счета с семьёй и друзьями, разделение расходов, лента, комментарии и уведомления.

## Стек

| Слой | Технологии |
|---|---|
| Backend | Go, chi, slog, golang-migrate |
| Frontend | React |
| Хранилища | PostgreSQL, Redis, MinIO (S3, аватары) |
| Взаимодействие | REST и SSE (фронт ↔ gateway), gRPC (между сервисами), Kafka (события), Redis Pub/Sub (уведомления) |
| Инфраструктура | Docker, Kubernetes |

## Быстрый старт (целевое состояние)

```bash
make up        # postgres, redis, kafka в docker compose
make migrate   # миграции всех сервисов
make run       # запуск сервисов локально
```

Пока в репозитории только заготовка HTTP-сервера в `cmd/server`. Порядок работ описан в [роадмапе](docs/08-roadmap.md).
